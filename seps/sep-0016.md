# SEP-16: Documentation

- Status: Draft
- Criteria: 0/6 done

## Motivation

Docs are the reference for how features work and the mental model. v1's failures to avoid: half of node pages under 40 words, concept stubs, docs contradicting code, translations that went stale silently.

## Open questions

- Deferred: the governance book (Power, Vote, Delegate, Reputation) is written after the community vote and the work in SEP-7, because nothing in it is confirmed yet.

## Criteria

- [ ] SEP-16.1: User docs live as Markdown in the repo in five sections (Tutorials, How-to, Reference, Concepts, Coming from v1) and build into a static site; the site is published to `docs.superalgos.org` by CI only after a manual approval step (a protected environment), never on push alone.
  Probe: ci: docs workflow on push vs on approval. Pass: builds on push; publishes only after approval. Tool: GitHub Actions environment.
- [ ] SEP-16.2: Reference pages (strategy fields, indicators with params and outputs, CLI commands and flags, signal and event kinds, tier and relay defaults) are generated from the code and schemas; a CI check fails when a generated page is out of date.
  Probe: ci: change a default in code without regenerating. Pass: CI fails naming the page. Tool: generator + diff.
- [ ] SEP-16.3: Every command and JSON example in the docs runs in CI and passes; a page with no body text beyond its title fails the build (no stubs).
  Probe: ci: docs examples; an empty page. Pass: examples pass; empty page fails. Tool: doc test runner.
- [ ] SEP-16.4: Dashboard fields and errors link to their reference page (context help).
  Probe: test+browser: each dashboard field help link. Pass: resolves to an existing page. Tool: bun test + Chrome.
- [ ] SEP-16.5: Reused v1 pages go through a JSON-to-Markdown converter plus a human edit pass; credit and the Apache-2.0 notice for reused v1 material are in `NOTICE`; a "Coming from v1" page holds the v1 → v2 term map and what was dropped.
  Probe: review+grep: converted pages; NOTICE. Pass: edited; credit present. Tool: rg + review.
- [ ] SEP-16.6: English is the source language; translations are managed per text segment in an open-source translation platform (Weblate proposed), so a changed English segment marks its translations outdated instead of leaving them silently stale; the site shows untranslated or outdated segments in English with a notice.
  Probe: integration: change an English segment. Pass: its translations flagged outdated; site falls back with notice. Tool: translation platform + site build.
