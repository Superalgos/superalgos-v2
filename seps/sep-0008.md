# SEP-8: Market chart

- Status: Implemented
- Criteria: 7/7 done

## Motivation

A trader picks any market, sees candles and the strategy's technicals exactly as the engine computes them, sees every signal on the chart, and can take the signals away as a verifiable file, without running anything on a third-party platform.

## Criteria

- [x] SEP-8.1: The chart renders real candles for a user-selected Binance spot instrument and timeframe served by sa-api.
  Probe: browser: select ETHUSDT 1h. Pass: candles render, values match Binance klines. Tool: browser (Chrome) + pytest.
- [x] SEP-8.2: Indicator values drawn on the chart equal sa-engine's indicator outputs for the same candles (same code path, equality test).
  Probe: test: API indicator series vs sa_engine indicators on fixture candles. Pass: identical. Tool: pytest.
- [x] SEP-8.3: A provider's signals appear as markers at their creation times on the chart, with tier release times on hover.
  Probe: browser: provider page chart. Pass: one marker per signal at created time. Tool: browser (Chrome).
- [x] SEP-8.4: The user can search and select any Binance spot instrument and switch timeframe (1m to 1d).
  Probe: test+browser: symbol search + timeframe switch. Pass: any Binance spot symbol loads. Tool: pytest + browser (Chrome).
- [x] SEP-8.5: A stored backtest's entries and exits appear on the chart at the times and prices in its BacktestReport.
  Probe: test: backtest overlay markers vs report fills. Pass: identical times/prices. Tool: bun test + pytest.
- [x] SEP-8.6: Signals export from the dashboard as a signed bundle (JSON) and CSV; the exported bundle passes `sa verify`.
  Probe: e2e: export bundle → `sa verify`. Pass: complete, signatures ok. Tool: pytest.
- [x] SEP-8.7: Anti: any code path executes strategies on, or sends strategy logic to, TradingView or another third-party platform (charting library is bundled locally, no CDN).
  Probe: grep: Pine sources, TradingView webhook/alert or API calls, CDN script tags in first-party code (the library's required attribution link is allowed). Pass: 0 hits. Tool: rg.
